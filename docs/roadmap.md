# Alpha 0.1 开发路线

## 当前：仓库初始化（已推送 GitHub）

- [x] 原始 V1.6.2 制作包完整归档
- [x] 最新美术与叙事/经营拆分决议
- [x] 原版 V0.2 Galgame 体验原型归档
- [x] React / TypeScript / Vite 前端骨架
- [x] 可测试的第一周纯状态演示（独立于 UI）
- [x] 远端 GitHub 仓库创建并推送

## M1：第一月核心闭环（优先）

- [ ] 数据驱动剧情引擎：对白、立绘、背景、姓名条、可条件化的选项、对话回看/自动/快进
- [ ] 一体化世界状态：日历、日程、艺人、作品、通告、资金、口碑、敌对度
- [ ] 第1个月可安排、推进、触发、结算；时间与档期冲突有效
- [ ] 通告系统：竞标、成本、艺人分成、录制周期、结果质量、收益
- [ ] 手机/热搜与舆情危机；公关选择实际改变系统状态
- [ ] 本地存档读档与版本迁移
- [ ] 手机竖屏适配，基础可访问性，关键路径自动化验收

## M2：经营深度

- [ ] 多艺人培养、档期、合约；公司等级与部门升级
- [ ] 经济模型可配置，首月到一年长时模拟
- [ ] 星煌敌对度采用内部分值 → 四档 UI 映射

## M3：长线内容

- [ ] 选秀赛事多阶段、晋级公式验证
- [ ] 老情人/羁绊事件、反向挖角、复出机制
- [ ] 证据线与多结局，真实条件检查

## 不做

- 不把 285 条制作素材作为游戏内「素材仓库」直接展示
- 不新增钻石、金币、固定爱心进度条
- 不将主要剧情变为仪表盘中的文本卡片
- 不直接复制任何参考游戏的立绘或 UI 资产
