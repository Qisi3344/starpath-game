## 第一章 游戏核心定位与开局设定

### 1.1 核心玩法定位

玩家扮演被雪藏的过气顶流，自立门户开经纪公司，发掘培养艺人、对接影视商务资源、处理行业公关危机，从小工作室逐步成长为娱乐巨头，最终向当年陷害你的行业巨头星煌娱乐复仇。

主打「轻数值重体验」，用场景化、事件化代替纯数值模拟器，适配竖屏手机端单手操作。

### 1.2 开局设定：过气顶流退圈创业

**背景**：你曾是3年前的顶流偶像，因被对家星煌娱乐设计的绯闻雪藏，合约到期后拿着微薄解约金，决定自己开经纪公司捧新人，同时向当年打压你的行业巨头复仇。

**初始资源**：
- 启动金200万
- 0签约艺人（第1天陆星遥找上门，第2个月沈亦辰加盟）
- 「业内人脉」buff（通告竞标成功率+10%）
- 「负面标签」debuff（高端品牌初始好感-20）
- 宿敌公司「星煌娱乐」初始敌对

**紧迫感来源（5条鞭子，不让玩家躺平）**：

1. **烧钱线**：200万启动金看着多，但初期月固定支出约10-12万（公司升级中型后涨至15-20万），不赚钱约18个月烧完

2. **星煌打压阶梯（与阶段时间线对齐）**：
   - 第0-6月：无视你（新手保护期，仅嘴炮无实质打压）
   - 第6月-2年：小打小闹（抢小通告、买小黑稿）
   - 第2-3年：正式打压（挖你艺人、垄断平台资源、爆黑料）
   - 第3年+：全面战争
   - 注：玩家反向挖角星煌艺人成功，会使星煌敌对度升一档，可能提前触发打压升级——挖得越狠，被打得越狠

3. **沈亦辰合约倒计时（前期压力，不是终局）**：他只签了1年约，第1年末如果公司旗下有B级及以上艺人（不含他本人）+实现月度盈利，他就续约5年；如果没做到他走人，但不是Game Over，只是损失前期收入支柱（修订注：原"公司有B级艺人"含他本人则恒成立，已明确排除）

4. **年度行业评估**：每年底行业排名，排名太低会被嘲讽+平台资源降级

5. **陆星遥舆论压力**：素人+前后援会长身份，持续被骂"走后门"，不出作品路人缘持续掉

**新手期容错放宽（前6个月强制生效）**：
- 不会触发任何重度负面事件，最多出现轻度绯闻、小失误
- 星煌无实质资源打压（不抢通告、不挖人、不封锁平台），嘴炮嘲讽不属于实质打压
- 首次接通告必定竞标成功（新手保底机制，与加成无关）（修订注：原"+20%保证必成"表述矛盾，+20%不等于100%，已改为明确保底）
- 艺人塌房概率降低50%
- 两项保底收入：旧作版权长尾每月3-5万（持续1年）；第2个月前辈友情代言30万（稳拿）
- 破产兜底：资金低于20万触发沈亦辰借钱选项（最多50万无利息，后续半年分成降5%）；资金为负进入3个月赤字缓冲期，3个月还不上才Game Over

### 1.3 核心循环与时间流转

**时间单位：按天推进 + 日程制快进**
- 最小单位：天（娱乐圈拍戏、热搜、通告都是按天算的）
- 游戏内顶部常驻显示「第X年 X月X日」
- 默认流速：1天 ≈ 8-10秒现实时间，一年≈50分钟-1小时
- 可调节：暂停 / 1x / 2x / 4x
- 智能快进：点「跳到下一个待办」直接跳过空闲期，有事件自动暂停
- 视图切换：日程可看日视图/周视图/月视图，安排长期工作用月视图，处理突发事件用日视图
- 不是每天都要操作——有事件/待办的日期标红点，空闲期一键快进

**玩家核心循环（每分钟手指在忙什么）**
```
刷手机看热搜/消息（10秒）
→ 发现机会或危机（5秒）
→ 给艺人排日程/接通告/做公关选择（20秒）
→ 快进等待结果（可一键跳过）
→ 事件触发，做2选1/3选1决策（10秒）
→ 看结算反馈（人气涨了/掉了，到账了）（10秒）
→ 循环
```
本质是「安排→等待→突发事件→决策」，不是每天点点点的体力游戏。

**终局后可继续玩**：终局剧情打完后进入「自由经营模式」，没有结束，可以继续扩张、捧更多艺人、收集成就、尝试行业垄断。终局只是主线剧情的收尾，不是游戏关闭。

### 1.4 游戏阶段时间线（无硬上限，主线3-5年自然触发）

| 阶段 | 时间 | 核心目标 | 主要对手 | 压力来源 |
|------|------|----------|----------|----------|
| 新手生存期 | 0-6个月 | 活下来、捧出第一个C/B级艺人 | 无（星煌无视你） | 烧钱线、沈亦辰合约倒计时 |
| 成长扩张期 | 6个月-2年 | 公司升中型、有1-2个B级艺人 | 潮娱文化（抢资源）、新锐工作室（抢新人） | 星煌小打压、潮娱正面竞争 |
| 巨头对抗期 | 2-3年 | 公司升大型、有S级艺人、集齐复仇证据 | 星煌正式打压 | 星煌挖人、垄断平台、爆黑料 |
| 终局对决期 | 3-5年 | 触发终局，多结局 | 星煌全面战争 | 最终对决3个月反击窗口 |
| 自由经营期 | 5年+ | 无固定目标，自由扩张/收集成就 | 任意 | 艺人年龄增长、转型压力 |

> 注1：没有硬性时间deadline，不会"5年到了没打败星煌就Game Over"。复仇线条件集齐就触发终局，快的3年，慢的5-8年，想拖到10年+也行。
> 注2：10年以上面临艺人年龄问题——偶像吃青春饭需转型、演员黄金期过了接戏降级，长线玩有长线的挑战。
> 注3：沈亦辰1年合约是前期鞭子，不是终局倒计时。第1年末公司有起色他就续约5年，即使他走人也不是Game Over。

### 1.5 终局判定与多结局

**市值定义（轻量化，不做复杂财务）**

市值 = 公司估值，由四项加权自动计算，玩家只看结果不用算：
- 现金储备（30%）：账上可用资金
- 签约艺人总商业价值（40%）：所有艺人商业价值之和
- 待结算项目收益（20%）：在播剧、待播综艺、未结算代言的预估收益
- 公司口碑（10%）：行业内评价与平台好感度综合

呈现方式：公司页面顶部显示「当前市值：XX万」「行业排名：第X名」，每季度更新一次。终局条件「市值行业前2」明确对标：超过潮娱、正艺，追平或超过星煌。

**证据线主动玩法（复仇结局必需，不是白给）**

共3个关键证据，玩家主动触发、花钱/耗人脉收集，集齐解锁终局对决：
1. **前助理证词**（第1年可触发，修订注：原第1.5年，与老情人节点1撞车，提前错开）：花50万+人脉收买星煌前助理，拿到当年雪藏你的内部邮件
2. **原始合约文件**（第2年可触发）：通过法务部挖旧档/买通内部人员，拿到当年被篡改的合约原件
3. **高管反水·老情人剧情线**（第2.5年可触发）：详见下方

**老情人剧情线（证据3深度版，主线绑定角色）**

- **身份**：当年陷害事件的知情者，现任星煌高管（金牌经纪人/副总级别），与玩家有过一段感情
- **立场摇摆**：在「帮你递证据」和「为自保出卖你」之间横跳，不是纯工具人
- **关键抉择点（2~3个）**：
  - 深夜天台见面：谈旧情还是谈交易（影响后续获取成本）
  - 他/她被星煌怀疑时：保还是弃（保则消耗人脉资金，弃则证据线断裂但无风险）
  - 最终摊牌：选择让他/她出庭作证还是黯然离场
- **对证据3的影响**：选择不同，证据3的获取成本（50万~200万+人脉）与成功率（40%~90%）不同；失败会被反咬一口，公司口碑-10
- **终局收束**：复仇结局时出庭作证则处刑更彻底（星煌核心层全部倒台）；联盟/商业帝国结局各有对应收束剧情
- 说明：老情人是主线绑定的深度角色，不走10.7通用羁绊框架

**复仇主线结局（推翻星煌）**：集齐3个条件触发终局剧情——
1. 捧出至少1名SS级国民艺人（须为旗下签约艺人；玩家本人复出上限为S级，不计入——见2.6）
2. 公司市值进入行业前2
3. 掌握星煌当年陷害你的3份证据

集齐后触发「终局对决」：星煌发动总攻（同时爆黑料+挖顶流+垄断平台），3个月反击窗口，最终在年度颁奖礼上真相曝光，星煌崩盘。

**四种终局可选**：
1. **复仇结局**：收集证据+颁奖礼处刑，星煌崩盘，最爽的主线结局
2. **商业帝国结局**：市值行业第一，不一定搞垮星煌，双雄并立
3. **联盟结局**：联合正艺传媒等公司制衡星煌，形成三足鼎立的行业新秩序
4. **小而美结局**：不追求规模，旗下艺人零塌房，口碑封神，安稳赚钱

## 第二章 核心养成：艺人系统

### 2.1 四大赛道定位

| 赛道 | 核心属性 | 优势 | 劣势 |
|------|----------|------|------|
| 偶像 | 颜值+唱跳+人设 | 吸粉快、商业价值高 | 塌房代价大、吃青春饭 |
| 演员 | 演技+国民度 | 生命周期长、上限高 | 成名慢、周期长 |
| 歌手 | 唱功+作品 | 粉丝粘性强、长尾收益 | 出圈难、曝光低 |
| 综艺咖 | 综艺感+情商 | 来钱快、曝光高 | 消耗神秘感、咖位上限低 |

### 2.2 属性体系

- **公开属性**：主能力（演技/唱功等）、颜值、气质、逼格（时尚资源向）、情商、路人缘、人气值、商业价值
- **隐藏属性**：敬业度、私生活混乱度、抗压能力、野心值（仅通过行为事件感知，不直接显示精确数值）

### 2.3 咖位分级

D级（练习生）→C级（十八线）→B级（二线）→A级（一线）→S级（顶流）→SS级（国民级）

每级提升需满足：主能力达标 + 人气门槛 + 代表作数量（初版建议值，可调）：

| 晋升 | 主能力 | 人气门槛 | 代表作 |
|------|--------|----------|--------|
| D→C | ≥60 | ≥1万 | ≥1部 |
| C→B | ≥70 | ≥5万 | ≥2部 |
| B→A | ≥80 | ≥30万 | ≥3部 |
| A→S | ≥90 | ≥150万 | ≥5部 |
| S→SS | ≥95 | ≥800万 | ≥8部（含1部爆款）|

### 2.4 艺人签约四大途径（含反向挖角）

1. **星探挖掘**：低成本，属性随机，概率出天才素人
2. **选秀签约**：成本中等，属性可见，自带初始人气
3. **同行挖角**：高成本（付违约金），自带人气作品，忠诚度低
4. **自荐上门**：随机事件，质量参差不齐

**反向挖角——从星煌挖人（同行挖角的特殊子项，复仇反制手段）**
- **解锁条件**：游戏时间≥2年（与「前2年没资格正面对抗」对齐），公司等级≥中型
- **成本**：违约金为正常挖角的2倍（星煌系数）
- **星煌旧部标签**：挖来的艺人能力/人气高于同级平均，但忠诚度上限低，有概率触发「被星煌策反」事件
- **目标池**：以星煌B级/A级艺人为主；S级需特定事件解锁（如对方与星煌闹解约、老情人暗中帮忙）
- **敌对联动**：每次挖角成功，星煌敌对度升一档，可能提前触发打压升级——挖得越狠，被打得越狠，形成博弈

### 2.5 初始艺人阵容与设定

**开局阵容：固定2人（一老带一新，不搞足球队）**
- 第1天：陆星遥主动找上门（D级偶像·素人）
- 第2个月：沈亦辰约吃饭提出加盟（B级双栖·前队友）
- 第1-3个月内：通过星探/自荐自然补1-2人，逐步扩充到4-5人
- 半年左右：正常小公司规模6-8人

**陆星遥（偶像·D级）**
- 玩家前核心后援会长，零底薪愿意加入，绝对忠诚永不被挖角
- 自带玩家老粉支持，初期吸粉速度+30%
- 实力一般，容易被骂"走后门"；中期被扒后援会长身份引发争议
- 公开属性：颜值82，唱跳55，情商70，路人缘45，人气值5000
- 隐藏属性：敬业度85，私生活混乱度5，抗压能力60，野心值40，忠诚度100

**沈亦辰（歌手/演员双栖·B级）**
- 玩家前队友，过气男团成员，自带出道经验和人气
- 有腰伤，高强度工作30%概率停工1-2个月
- 中期星煌拿当年黑料威胁他跳槽
- 公开属性：颜值78，唱功75，演技60，情商70，路人缘55，人气值80000

### 6.4 核心计算公式

- **出道概率** = 人气排名分×0.6 + 平台好感度×0.2 + 公关投入×0.1 + 公司人脉×0.1（各变量均换算为0-100分制，结果即概率%）
- **外签选手违约金** = 选手当前商业价值 × 2.5

## 第八章 美术风格与竖屏移动端UI交互设计

### 8.0 美术风格总览

- 采用「胸像+肩颈光影」的卡片式立绘，适配竖屏艺人卡片，不占空间又有足够表现力
- 咖位差异化质感：D级是生图感、B级是精修营业图、S级是杂志大片感，不用看数字一眼识别咖位
- 玩家本人立绘：开局是「过气旧照」磨砂质感，复出成功后解锁高定大片版，直观体现状态变化

**场景美术**

## 第十章 补充玩法与细节优化

### 10.1 颁奖季与行业奖项

- 每年12月固定颁奖季，四大赛道各2-3个主流奖项（演员：最佳新人/配角/男主；歌手：最佳新人/年度金曲/最佳专辑）
- 提名自动按「当年作品质量+人气」筛选，无需玩家报名
- 玩家操作：不公关（纯靠实力）/ 小额公关50万（提升提名概率）/ 重金拉票200万（提升获奖概率）
- 获奖收益：直接升0.5个咖位、商业价值+30%、次年通告优先级提升

### 10.2 档期效应

- **暑期档（6-8月）**：剧集、综艺播放量+30%，偶像曝光收益+20%
- **贺岁档（11-12月）**：电影票房+50%，商业代言报价+15%
- **颁奖季（12月）**：公关事件翻倍，奖项相关操作生效
- **春节月（1月）**：通告减少一半，艺人请假概率提升
- 接通告时标题旁标「暑期档」「贺岁档」小标签

### 10.3 复仇线新手引导（前7天手机消息）

无强制弹窗，通过「我的手机」按天推送引导消息：
- 第1天：沈亦辰「解约金到账了？办公室我帮你找好了，明天过来看看？」
- 第2天：陆星遥「哥/姐！我听说你开公司了！我能来吗！我什么都能干！」
- 第3天：前助理「星煌那边知道你开公司了，最近可能会有动作，小心点」
- 第4天：财务「本月固定支出已出，房租+水电+人员工资，余额还剩XXX万」（修订注：沈亦辰第2个月才加盟，Day4不应有其薪资）
- 第5天：星煌官方号发微博「某些过气艺人还想翻身？可笑」→ 上热搜，触发第一次公关选择（注：此为嘴炮挑衅，不属于实质资源打压，不违反新手保护）
- 第6天：沈亦辰「有个小综艺在找人，我帮你问了，陆星遥要不要去试试？先赚点钱」（修订注：此时他尚未加盟，是以朋友身份介绍资源）
- 第7天：陆星遥「我今天去试镜了！导演说我还不错～」

### 10.4 日常随机小事件库

每月随机触发1-2个，绝大多数仅展示，少数给2个极简选项：
- 正向：被导演夸演技涨小口碑、路人偶遇拍图上小热搜、品牌方寄免费样品
- 中性：艺人请假回家、想养宠物、推荐朋友来面试
- 小负面：拍戏崴脚休息3天、被拍丑照上娱乐号、采访说错话招小黑粉

### 10.5 公司群聊彩蛋

- **公司工作群**：经纪人发行程通知、财务发报销提醒、公关发舆情预警
- **艺人小群**：艺人私下聊剧组八卦、吐槽盒饭、约着吃饭，不同性格说不同的话
- 纯展示无需玩家回复，每天刷几条新消息

### 10.6 可选中长期拓展方向

1. **艺人转型路线**：偶像转演员、歌手转综艺咖，转型期人气小跌10%-20%，成功后解锁新赛道
2. **公司业务线拓展**：升级大型集团后解锁唱片厂牌、影视制作分公司，提高分成比例
3. **行业年度排行榜**：每年初发布上年公司市值榜、艺人权力榜、作品热度榜，纯展示
4. **经纪人-艺人性格适配**：合拍组合发消息更积极（纯文案表现），相冲组合偶尔斗嘴（纯文案），不影响任何数值与事件概率（修订注：原"少出状况/小矛盾"与9.1"性格不关联数值"矛盾，已改为纯表现层）

### 10.7 羁绊事件线（瘦身版攻略）

**定位**：不做通用好感度系统、不做修罗场数值。3~4个特定NPC，每人一条专属事件线，复用现有事件/公关/人脉框架。老情人走主线绑定（见1.5），不走本通用框架。

**对象**：
1. **品牌方千金/继承人（商务线）**：暧昧期品牌合作成功率提升；曝光则触发公关危机+品牌好感波动
2. **对家（潮娱/正艺）想跳槽的金牌经纪人（挖角线）**：挖角前置剧情，谈得好可免违约金直接来投
3. **（可选高压线）旗下艺人**：一旦曝光必定触发中度以上公关危机+全员忠诚度波动，给喜欢走钢丝的玩家准备的

**规则**：
- 每人3~5个事件节点，选项推进关系阶段（相识→暧昧→确认关系），无数值面板
- 所有恋情曝光统一走第7章公关系统：一般恋爱绯闻为轻度事件；与旗下艺人曝光升格为中度
- 与合作方确认关系：对应合作成功率+10%；分手/曝光则-15%，并关闭一条合作通道三个月
- 复杂度声明：不新增任何数值体系，全部落在事件选项+现有系统联动

## 第十一章 复杂度控制原则

### 11.1 轻量化核心准则

1. 不新增冗余数值体系，新功能只做表现层包装，复用现有数值
2. 信息分层开放，前期功能少，随公司升级逐步解锁
3. 操作极简，以「选选项+花钱」为主，避免复杂养成线
4. 隐藏属性不透明，靠事件与行为感知，不堆数字面板
5. 最多3次点击到达任何操作，避免层级过深
6. 数值口径：所有公式变量统一换算为0-100分制代入，结果即百分比；人气单位为个位数（与艺人面板一致），涉及"万"时明确标注

### 11.2 不建议新增的内容

1. 详细员工管理（招聘、考勤、绩效考核、工资）
2. 复杂财务做账（税务、成本分摊、财报）
3. 深度粉丝运营系统（打榜明细、后援会管理、反黑站）
4. 多城市、多分公司的大地图扩张
