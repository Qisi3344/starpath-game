**状态：导航已由用户确认（2026-10-12）**。唯一正式五 Tab 顺序：**工作室／艺人／娱乐圈／日程／通告**。顶部：左老板个人档案、右手机消息。视觉统一 C 方案、全员黑白剪影（ADR-0004）。

## 页面树

```text
GameShell（PC 居中 412px / 手机全屏 + safe-area）
├─ 顶部左：老板个人档案入口 → ProfilePage 全屏层（可关闭返回原页）
├─ 顶部中：游戏日 · 资金 · 口碑
├─ 顶部右：手机入口（未读角标）→ PhonePage 全屏层（可关闭返回原页）
├─ Tab 1 工作室 / company（默认入口）
│   ├─ 老板总览 · 待办 · 林知夏/员工报告 · 进度（M1 界面）
│   ├─ 经纪办公室／部门建设（后续）
│   └─ 招募委派任务（后续与日程/地图共用一份任务）
├─ Tab 2 艺人 / artists
│   └─ 艺人列表 → 艺人详情 → 作品/成长/合同/档期（逐步接入）
├─ Tab 3 娱乐圈 / map
│   └─ 五大城区：北 / 东 / 西 / 南 / 新
│       └─ 区域详情 → 事件/人才/资源/外派（区域详情初版可点，真实派遣后续）
├─ Tab 4 日程 / schedule
│   └─ 当前游戏日/本周记录 → 培养/通告/派遣排期（现有日历初版，冲突计算后续）
├─ Tab 5 通告 / gigs
│   └─ 通告市场 → 项目详情 → 艺人分配 → 合同/收益（逐步接入）
├─ 剧情 StoryPlayer · 任何 Tab 触发，返回发起地点
├─ 结算报告 · 临时全屏层
└─ 设置与存读档 · 从个人档案入口进入，M1 后续
```

## 交互红线

1. **五个 Tab 的顺序和文字是产品决议**，不可继续给用户做多选题，不生成多套导航主题。
2. 通过 `src/ui/navigation.ts` 的 `TABS` 唯一数组设置五大入口，`TabId` 必须与之同步。
3. 每个 Tab 有**独立二级页栈**：切走后回来仍是原页面；二级的返回只弹出当前 Tab 的最近一页。
4. 手机/个人档案/剧情/结算是独立全屏层；关闭时返回触发前 Tab 与页面。
5. 顶栏在 Galgame 全屏剧情隐藏；不将手机与个人档案加入底部。
6. **大地图不能只是纯占位**：M1 至少具备城区入口、详情和返回。将来外派与通告由共同任务 ID/世界状态驱动。
7. **真实业务尚未接入时**，详情页如实写明“待开发”，不能伪造资金变化、候选人或已完成任务。
8. 视觉统一 C，人物全员黑白灰剪影占位；不要根据效果图重命名固定角色。
