# 技术结构建议

## 主体

- `src/game`：独立于 React 的状态转换、计算器、规则、随机种子；可单测。
- `src/story`（待建）：剧情数据结构、节点条件、变量绑定、选项效果；剧情与经营双向更新。
- `src/ui`（待建）：竖屏布局、对话播放器、独立经营界面、统一手机界面。
- `src/assets`（待建）：正式美术素材，需记录许可与来源。
- `src/data`（待建）：版本化数值参数，不能在组件写死平衡公式。
- `src/save`（待建）：IndexedDB / localStorage 存档层，必须含版本号和迁移机制。

## 质量准则

- 任何选项 effects 不得只更新对白而忽略世界状态；
- 同一轮通告不得重复结算；
- 日程推进应对时间资源、冲突做校验；
- 经济参数可配置，SS 进阶前必须测算可达性；
- 新的开发决定必须在 `docs/decisions` 留痕。
