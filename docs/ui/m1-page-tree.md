## 二、导航与返回约定（无论导航方案选哪套都遵守）

1. **主 Tab 稳定**：切 Tab 不清空该 Tab 内的二级栈；剧情全屏与结算模态盖住 Tab 栏。
2. **二级返回**：二级页左上 `〈 返回`；浮层点遮罩或关闭钮；任何路径不困死（返回链到主 Tab 为止）。
3. **剧情回跳**：剧情从哪个页面发起，结束回哪个页面；回看面板不改变剧情进度。
4. **推进唯一入口**：游戏日推进只发生在「工作室总览的推进按钮」与剧情内指定节点；有未处理的重大事件（审批/危机）时禁止推进。
5. **同一数据多入口**：候选资料、通告详情等从消息与业务页进入的是同一实例，不复制状态。
6. **刷新/读档落点**：恢复世界状态后，界面至少落回「公司 Tab 工作室总览」。
7. **单竖屏舞台**：PC 与移动共用组件与状态，PC 只是居中呈现，不写第二套业务逻辑。

## 三、Tab 配置的实现位置

Tab 集合是唯一配置点：`src/ui/navigation.ts` 的 `TABS` 常量。玩家确认导航方案后，只改这一处（附页面 id 映射），页面组件本体不动。
