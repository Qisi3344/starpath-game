# ADR-0004 · 《星途计划》最终视觉方向与立绘占位原则

状态：**已确认视觉方向与占位方式（2026-10-12）**；细部颜色、版式数值与正式美术仍可迭代。

## 1. 唯一正式方向：C「现代梦感叙事」

用户从三张 UI 方向图中明确选择 **C（第一张）**。项目只维护**一套原创 UI 主题**，不做主题切换设置。A/B 是设计过程中的对比材料，不代表多个可供玩家切换的主题。

设计核心：**现代都市、温柔梦感、细腻 Galgame 叙事 + 可信的经纪模拟经营**。整体以柔和奶油白、暖灰粉、低饱和玫瑰紫、深梅棕与克制香槟金建立层次，**不用商务蓝**。

补充优化（同属唯一 C 方案，不构成混搭换肤）：
- 工作室与高频经营界面略向 A 学习温暖日光、清晰留白与高对比可读性；避免大块脏灰紫。
- 艺人宣传、通告海报、颁奖礼和高光时刻可适当借鉴 B 的编辑式精致感，不把整个小工作室变成豪华总部。
- Galgame 保留 C 的大场景、人物视觉焦点、姓名条、对白框和少量关键对话选项。日常对白逐句推进，非关键处不强制出现选项。
- 概念效果图里的名字、数字、面板内容全部视为**美术占位**，使用项目正式文档内的人物与数值；用户未主动替换人物设定。
- 标题/正文避免宋体、明朝体、仿宋等明显强衬线；优先清爽可读的圆润文字与手写感标题，兼顾中文长文与小字。
- 不直接复制任何参考游戏的美术资产、构图、标志性 UI 和交互。

## 2. 正式美术前：黑白人物剪影占位

所有出场人物（包括林知夏、陆星遥、沈亦辰、老情人、剧情 NPC、后续艺人）暂时**统一使用黑白/深灰剪影立绘**。不能再把临时彩色人脸画得像已定稿的角色，也不从效果图挪用随机的临时名字。

占位资产要求：
1. 每个角色按稳定的 `characterId` 关联一个立绘槽位；没有单独美术的角色仍使用统一剪影生成/默认模板，避免缺图或错误借用其他角色立绘。
2. 剪影有成人体型及角色类别的差别（发型、服装、站姿、肩颈轮廓），但**不暗示确定的发色、瞳色、面容、配饰细节**；仅黑、白、深灰，中间灰用来表现层次。
3. 背景透明，适配 Galgame 的下半身裁切 / 半身 / 全身；同一角色在剧情、档案、候选卡片等场合复用相同 `characterId` / 统一人物资产注册表。
4. 无正式表情资产时，仅设置 `neutral` 的可复用占位槽，剧情数据可提前预留表情关键字；**不强求剪影生成五官表情**。
5. 正式立绘制作后只换对应资产映射和参数（位置/缩放/表情），**不改剧情与经营逻辑**。
6. 强调无性别预设的角色库：可包含成年男性、女性和多种性别表达的艺人/NPC，不能由样板的女性头像决定人物设定。

## 3. 底部导航已独立定稿（ADR-0005）

玩家于 2026-10-12 确认底部固定顺序：**工作室／艺人／娱乐圈／日程／通告**；顶部保留**个人档案**和**手机消息**，默认首屏是工作室，娱乐圈地图为正式一级功能。

UI 视觉只采用 C 方向，与五个入口的业务职责分别遵从 ADR-0004 与 ADR-0005；**不再把地图与导航当成待确认事项**。

## 4. 技术落地

- 全站只使用 `src/ui/tokens.css` 的单一 `:root` token，禁止 `data-art` 多主题切换。
- 暂定立绘资产接口为：`CharacterArtwork({ characterId, expression?, variant? })`，剧情仍调用同一人物注册表。
- 剪影为纯占位，可直接代码绘制 SVG；不是最终美术。
- 竖屏移动优先，剧情和经营两套布局共享这套视觉语言与全局状态。
