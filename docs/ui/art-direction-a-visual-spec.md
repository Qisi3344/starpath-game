## 二、视觉规格提炼（token 映射）

- **底色**：奶油米金（比 V0.2 的粉灰奶油更暖更黄，纸感）。`--surface-base: #f6efe7`、舞台外围 `#efe4d8`。
- **卡片**：纯白至奶油白，大圆角 18–20，柔影。`--surface-raised: #fffdf9`。
- **文字**：深暖棕（V0.2 是紫灰调，方向 A 转暖棕）。`--text-main: #4f4139`、`--text-muted: #8d7f75`。
- **主强调**：玫瑰豆沙粉（姓名条、激活 Tab、主按钮）。`--accent-primary: #c17f92`、hover 深一档 `#b06a80`；浅粉底 `--accent-soft: #f4dfe0`。
- **金点缀强化**：金币徽章、香槟金细节。`--accent-gold: #d9b98a`。蓝仅作宝石点缀色出现（赞助金钻石图标），**不是界面主色，不构成商务蓝**。
- **分类辅助色板**（新增，日程色块/候选人徽章用）：浅紫 `#e6dff0`、浅蓝 `#dfe9f4`、浅粉 `#f7e3e4`、浅金 `#f4ead8`。
- **字体层级**：日期、等级、热度数用衬线大数字（`--font-display` 已有）；正文黑体。眉标小字距全大写。
- **组件形态**：胶囊标签/按钮为主；属性条=浅槽+玫瑰填充圆头；快捷入口=粉底圆角图标格；徽章色按职业区分（演员粉/歌手紫/模特金）。

## 三、效果图与现有实现/决议的差异（全部待绮思确认，未擅动）

1. **导航出现第三变体**：图 02 底部 Tab 为「工作室 / 艺人 / 消息 / 日程 / 更多」——与原案「大地图/公司/艺人/通告/我的」和蓝图新提案「工作室/艺人/日程/通告/我的」都不同：手机被收进底部 Tab，日程升一级，大地图消失。**三个变体需她三选一**；`TABS` 配置未动，仍是原案。
2. **角色名不一致**：图中出现 苏黎（开场对话）、小柠（助理）、林夏（艺人）、许知愿/席芮/沈砌乔（候选人），与 ADR-0002 暂定的 林知夏/陆星遥 不同。按交接优先级（已确认决议 > 提案），实现保持 ADR-0002，不采纳图中名字；若她要改人物名需写新决议。
3. **助理执行细节**：图 04 的"可分配工作（助理执行）：资料整理/粉丝数据分析/行程确认 + 委托"是 ADR-0003 委派机制的具体化，方向一致，后续做日程页时按此实现。
4. **待审批流**：图 06 的"待审批 N 项"卡片与 ADR-0003「仅需要决策的事升级为玩家待办」一致，PhonePage 已预留"审批提醒"卡位。
5. 图 01 的三选项形态（主文案 + 次行说明）与现有 `.choice`（choice-text + choice-desc）结构一致；定稿后只需调整统一组件样式。

## 四、结论

方向 A 与 ADR-0001 的温暖原创原则一致，但**不是最终选定的主题**。A/B/C 是选稿备选，不应制作运行时切换；视觉定稿时统一修改 `:root` 下的单套 `tokens.css` 值。导航仍需由玩家另行选定，和美术选稿互不绑定。
