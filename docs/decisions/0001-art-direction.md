# ADR-0001 · 视觉与交互的最新确认方向

状态：**已确认**。来源：2026-10-08 玩家对 V0.2 Galgame 视觉 demo 的反馈。

## 决定

《星途计划》采用 **女性向 Galgame 叙事展示 + 具备深度的经纪经营游戏系统**。

- **视觉参考**：《恋与制作人》《恋与深空》等女性向游戏的层次、精致感、沉浸式人物互动；仅借鉴表现原则，独立制作资产。
- **色彩**：奶油白、柔雾粉、浅暖灰、香槟金、少量深莓紫；拒绝商务蓝/冰冷深蓝后台。
- **剧情**：场景铺底、角色立绘居中、人物姓名条、底部半透明对话框；点击继续，选择节点才浮出选项；支持回看、自动、跳转。
- **经营**：独立界面，拥有实质的排期、合约、属性、作品、财务和风险，不退化成纯选项小说。
- **两类体验共用一份游戏状态**：故事中的决策要真实影响资金、关系、热度、资源等。
- **工作室**：初期温暖紧凑，随经营成果自然扩建；温馨不意味着冲突情节柔化。

## 覆盖关系

本决议覆盖主策划 `第八章` 中商务蓝/冷调商业后台的美术建议，不否定该章中已经合理的竖屏适配、信息导航、手机等功能结构。

V0.2 原型是已获认可的**交互方向参考**，其中矢量人物和背景是占位资源，不是正式美术标准。
