# ADR-0002 · 开场人物与第一个星期的执行规则

状态：人物设定**暂定**；序章节奏**开发基线**。

## 人物

- **玩家**：三年前被星煌娱乐设计并雪藏的前顶流，现独立开公司；本人熟悉娱乐圈，但首次担任公司负责人。
- **林知夏**：建议为旧日贴身执行经纪、长期知己、如今的首席执行经纪；负责教程、公司日常和行业初步建议。尚未最终锁定其姓名与过去的全部细节。她不应直接掌握复仇关键证据，以免与证人 NPC 功能冲突。
- **陆星遥**：D 级偶像，玩家曾经的核心后援会会长，第一个签约艺人；初始人气 5000。
- **沈亦辰**：玩家前队友，主设计书规划在第 2 个月正式加盟，勿提前编成第 4 天的入职工资。

## 第一个星期

- Day 1：旧日经纪重逢 → 公司命名 → 陆星遥到访并签约
- Day 2：培养/日程安排
- Day 3：初始通告与竞标保底
- Day 4：通告执行
- Day 5：星煌舆情挑衅与玩家公关选项
- Day 6：反馈
- Day 7：通告、运营和公关成本结算

第一周 V0.2 是脚本化试玩，不代表最终模型和经济数值。后续开发第一个月时，必须保留玩家的可自由排期空间，不能完全线性剧情锁死。

## 关键约束

- NPC 只提出建议，不替玩家行动或决定。
- 不增加统一送礼好感度条；关系由条件化事件和行动后果推动。
- 初期核心体验：安排 → 等待 → 突发 → 决策 → 结算。
