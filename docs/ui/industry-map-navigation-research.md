## 关于本作的结论

地图**重要，建议保留为高可见度、可交互的一级功能**，但不是让老板本人跑腿。《星途计划》采用 V1.6.2 已提出的城市区域、行业资源与星煌长期对抗体系，并落实 ADR-0003 的**老板下指令→员工执行→定期汇报**：

- **资源版图**：电视台、摄影棚、音乐/唱片、品牌商务、媒体平台、选秀场馆、竞争经纪公司、公共事件地点等区域。
- **员工外派**：点击地点了解项目/人物/机会 → 指派经纪人或星探搜寻、沟通 → 用游戏日历完成 → 手机/办公室汇报 → 老板审批关键决定。
- **事件舞台**：大地图显示剧情事件所在区域、资源解锁、星煌势力动作、限时机遇；玩家可亲自介入少数关键拜访，但这不应成为每个通告的前置跑腿。
- **公司成长展示**：工作室→总部升级可能改变世界地图中的公司呈现、影响力覆盖与竞争态势。
- **地图不是通告列表的另一层皮**：既有物理地点，也要有地方关系、进入条件、短期/长期信息与事件；通告高频管理仍可从通告页直接执行。

## 底部导航提案：地图保留，并减少低频入口

建议先讨论一种五 Tab 的组合，**不是自动定案**：

`工作室 / 艺人 / 娱乐圈（地图） / 日程 / 通告`

- **工作室**：老板总览、员工汇报、部门发展、招募委派、资金、事件与月结算。
- **艺人**：角色立绘、属性、履历、合同、职业成长与羁绊。
- **娱乐圈（地图）**：行业地点/势力/资源/剧情事件分布，中央 Tab 专用标识，进入后可打开二级地点页。
- **日程**：日程安排、培养执行、跨艺人时间冲突与任务状态。
- **通告**：影视/综艺/商务/音乐项目市场、谈判、接单、作品履历。
- **手机**：顶部常驻独立入口，消息、经纪人汇报、艺人私信、热搜、关键审批。
- **老板个人/存读档/设置/历史档案**：顶部头像或工作室内“我的档案”，而非占据每天高频 5 Tab。
- **招募**：工作室+地图都可发起，候选人报告可从手机/工作室查看同一任务详情；不另开一级 Tab。

为什么这样排：
1. 让**地图确实是一级功能**，与每日高频经营并列；不丢掉原 V1.6.2 想要的娱乐圈世界感。
2. 工作室直接是进入游戏的默认落点，第一印象仍是温暖的小公司，保证初月操作直接；地图只要点击一次即可打开。
3. 手机消息不与底部消息 Tab 重复；个人档案相对低频，放头像里更合理。
4. 既不把每次找通告都变成跑图，也不会把地图沦为没入口的摆设。

## 地图首月最低可用规格（建议）

首月只搭 **2D 城市分区草图 + 4～6 个功能性地点/地区入口**，不需要第一版就制作 20+ 场景大图，也不需要地图自由缩放。
每个已开放地点至少有：地名、当前可做动作、可委派负责人、任务耗时/预算、近期变化与进入方式；未开放地区显示条件而非假按钮。
地图、工作室、通告、委派任务必须使用同一实体 id 和世界状态，不能各自创建同名伪数据。

### 至少一条横向验收流程

地图查看某制作公司正在征集新人 → 派出林知夏收集试镜/通告情报 → 经过若干游戏日 → 手机收到汇报 → 审批是否投递旗下艺人 → 通告市场显示更新 → 艺人排期变更。

## 注意

- 这套底部五 Tab **仍是讨论提案**，不代表用户已经选择；`ui/m1-shell` 分支当前原案导航暂不覆盖。
- 视觉已单独确定 C 方案；无需为地图另做第二套 UI 主题。
- 若制作地图的代价大，可先用保留入口的可用简化城市草图，再逐步丰富地图场景；不允许永远把地图设为“以后再说”的纯占位。
