# ADR-0005 · 五大导航与顶栏入口正式定稿

**状态：已确认（2026-10-12）**。此决议优先于 V1.6.2 原版第八章导航和先前未确认的 UI 讨论稿。

## 唯一正式底部导航（按顺序）

1. **工作室** `company`：开局默认落点；老板总览、林知夏/员工汇报、部门、资金、待办与公司发展。
2. **艺人** `artists`：已签约艺人、能力、履历、合约、职业路线、培养入口。
3. **娱乐圈** `map`：**一级大地图**，用于城区/势力分布、资源解锁、事件地点与员工外派；不是纯装饰，也不是老板逐地点跑腿。
4. **日程** `schedule`：统一日历，艺人培训、通告排期、员工委派、冲突与时间推进。
5. **通告** `gigs`：合作市场、角色试镜、音乐/影视/综艺/商务、谈判及执行结果。

## 顶部独立入口

- **个人档案（左上角头像）**：老板身份、复仇档案、存读档、设置、历史信息，不占底部 Tab。
- **手机消息（右上角）**：热搜、艺人私信、经纪人汇报、合作方消息、待审批；未读角标。
- 顶栏同时可显示日期、资金、口碑等最简资源信息；人物剧情全屏时隐藏导航和顶栏。

## 地图存在的理由

地图承载实际的娱乐圈世界、经纪公司竞争与员工外派。地图区域可显示解锁条件、正在发生的事件和可获取的真实项目线索；老板可以了解并派人处理，合同、资源、危机仍由老板审批。**保留高频的通告入口**，不要求所有项目先去地图跑一圈。参考调研：`docs/ui/industry-map-navigation-research.md`。

## 一级、二级与全屏层

- 每个底部 Tab 自己的二级导航栈；切换 Tab **保留该 Tab 原二级位置**，返回按钮逐层退出。
- 手机、档案、Galgame 剧情、结算为从当前页面拉起的全屏层；关闭后回到**原 Tab、原二级页**。
- 剧情的「返回工作室」文案可按发起位置动态展示；若为新开局，退出后回工作室。
- 顶部手机与个人档案是不同入口，不要把手机塞进底部，也不要将档案误改成「更多」Tab。
- 存读档、复杂大地图和真正委派执行系统按 Alpha M1 逐步接入；尚未实现的按钮要明确标明，不可假装任务完成。
- 最初先提供可点击的地图分区入口和详情/返回链，后续连上世界状态、员工外派与事件，不必等完整城市美术。

## 与视觉的关系

本导航规则**独立于美术选稿**。视觉唯一 C「现代梦感叙事」及黑白人物剪影占位参见 ADR-0004；没有主题切换功能。

## UI 验收

1. 五个 Tab 按指定顺序可操作，默认工作室、无多余「我的」Tab。
2. 左上档案、右上手机均可打开并回到原页面。
3. 艺人→二级页→切换娱乐圈→切回艺人：二级位置保留；后退正确。
4. 娱乐圈的分区详情能够进入并返回，未接入的业务不伪装成功。
5. 从二级业务页面进入剧情后，退出回到发起页；覆盖层不能卡住导航。
6. 在 360/390/430 手机宽度、安全区及 PC 居中竖屏均能正常显示，不遮挡点击。
