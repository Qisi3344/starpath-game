# ADR-0001 · 《星途计划》原创视觉与交互方向

状态：**已确认**。基于玩家对 V0.2 Galgame Demo 的认可及后续澄清。

## 项目定位

《星途计划》是**独立原创的娱乐圈经纪经营 + Galgame 剧情体验**。视觉上要求女性向、温馨、精致、耐看，但**不以任何现成乙游为 UI、玩法、人物或系统设计模板**。

特别澄清：玩家提到的其他乙游，仅用于沟通“温馨、轻盈、精致”的**抽象视觉气质**，不是要求复制、复刻或高度相似地制作这些游戏。实现规格及代码注释不应写成“仿某某游戏”。

## 实施原则

- **视觉**：柔和、温馨、有质感；优先奶油白、低饱和暖粉、暖灰、适量香槟金与深莓紫；方案并非固定色板，可按场景扩展。反对商务蓝、冷冰冰的企业后台风。
- **原创性**：所有色彩搭配、版式比例、图标、菜单、卡片、立绘、场景、音效和交互动效，都需要形成《星途计划》独有的语言。不复制其他游戏的具体 UI 排布、边框、画风、角色或视觉资源。
- **剧情**：以通行的 Galgame 对话交互为范式——场景背景、人物立绘、姓名标识、底部对白、点按推进；重大情节弹出对白选项；支持回看、自动播放、跳过已读。选项形式可因情节需要变化。
- **经营**：独立且有深度的经纪经营界面，包含人才发掘、能力训练、日程冲突、合约、通告、作品、财务、公关、竞争及成长目标；不做只点对话的空壳。
- **状态**：剧情和经营共用世界状态；剧情选择须真实影响经济、关系与后续事件。
- **工作室**：初期有小型工作室的日常温度，随着经营推进逐步扩建，但娱乐圈的现实压力、竞争与复仇仍要成立。
- **视觉布局优先级**：人物和剧情场景优先于数据密集面板；经营数据在独立的管理页面清晰呈现。减少磨砂玻璃泛滥、过多粉色、冗余动效。

## 不应误解为

- 游戏类型 ≠ 乙女恋爱手游：恋爱/羁绊可选，但主玩法始终是**艺人经纪与公司经营**。
- 女性向/温柔 UI ≠ 直接拿成熟手游 UI 翻版；也不等于所有角色软萌、所有冲突被淡化。
- 视觉参考 ≠ 玩法参考；**明星养成玩法应单独分析经营类游戏的机制，不借用乙游成长数值体系。**

## 文档优先级与落地

本决议覆盖 V1.6.2 原设计书第八章商务蓝/冷调后台的美术建议，不覆盖已确认的其他玩法规则。V0.2 仅作为互动节奏方向的原型，不锁死其人物/配色/排版。

以后提交 UI 前检查：1. 是否有原创辨识度；2. 是否柔和而不幼稚；3. 是否兼顾经营信息密度；4. 是否没有现成游戏的标志性布局和素材。

## 单一主题规则（2026-10-12 已确认）

- 《星途计划》正式游戏**只采用一套统一的 UI 视觉主题**，不做玩家设置中的主题选择、换肤、多套配色切换或运行时 `data-art` 切换逻辑。
- A/B/C 六屏效果图仅是**设计阶段对比**；玩家已正式确认**唯一 C「现代梦感叙事」**方向。细则见 ADR-0004，不需要再次征询选稿。
- 正式选定后，只维护一份权威语义设计变量与组件规范。设计师或开发者修改 token 进行美术迭代是允许的，但不能把草案并存做成产品换肤功能。
- PR #4 开发分支曾有的 `[data-art="direction-a"]` 可切换层**已移除**；后续只维护 C 方向下的单一语义 token。
