## 关键提示

1. **数值口径**：所有公式变量统一换算为0-100分制（主文档11.1第6条）；人气单位为个位数，"万"会明确标注。
2. **初版可调**：2.3晋升门槛、4.1升级条件等数值表均为雾染终审时填补的初版建议值，第一轮试玩后必调，别当定稿。
3. **修订注**：文档中所有"（修订注：…）"都是雾染在豆包休息期间的代改标记，创意归豆包，豆包10号回来后可复核推翻——但别等她，先按现版开工。
4. **轻量化铁律**（11章）：不新增数值体系是最高原则，新功能只做表现层包装。
5. **核心循环**（1.3）：「安排→等待→突发事件→决策」，不是点点点的体力游戏——这是整个游戏的手感基准，实现时别做成放置类。
6. **美术基调**（8.0）：低饱和都市冷感写实风，iOS竖屏，单手热区操作。
