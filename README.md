# 星途计划 · StarPath

> 女性向剧情体验 × 有深度的娱乐圈经纪经营模拟游戏  
> **状态：Alpha 0.1 初始化** · 内部开发资料，不是正式发行版。

## 游戏定位

你曾是娱乐圈顶流，三年前遭星煌娱乐设计陷害与雪藏。合约结束后，带着 **200 万** 从小型经纪工作室重新起步：发掘艺人、培养能力、竞标通告、安排档期、应对公关危机、调查旧案，并与行业巨头展开长期对抗。

**设计原则：剧情像 Galgame 一样沉浸；经营像真正的经纪模拟游戏一样有深度。** 采用竖屏移动端优先、温暖柔和的女性向 UI；不使用传统商务蓝后台风格。剧情与经营共享世界状态。

- `docs/source/`：V1.6.2 原始制作包，全量保留，作为内容依据（非全部开发锁定）。
- `docs/decisions/0001-art-direction.md`：基于玩家反馈覆盖旧版第八章的**最新视觉决议**。
- `docs/decisions/0002-characters-and-prologue.md`：开局角色关系和序章执行规则。
- `docs/roadmap.md`：Alpha 0.1 开发阶段和验收条件。
- `docs/decisions/0003-ceo-delegation.md`：**玩家是公司老板**，委派员工寻找/接洽新艺人、汇报候选人，玩家批准合同与重大经营决策。
- `docs/design/artist-career-and-emergent-stories.md`：艺人职业路线、作品履历与经营过程生成的故事（分阶段开发草案）。
- `prototypes/galgame-v0.2.html`：**可直接用浏览器打开试玩**的 V0.2 Galgame 交互原型（设计参考，尚非 React 正式引擎）。
- `prototypes/galgame-v0.1.html`：更早期的经营视觉探索（历史存档，不代表现行审美）。
- `src/`：React + TypeScript + Vite 的正式项目基础骨架，以及独立的纯函数经营状态演示。
- `tests/`：不依赖浏览器的关键状态与结算测试。

## 本地启动

推荐 Node.js 20.19+ 或 22.12+：

```bash
npm install
npm run dev
```

验证：

```bash
npm test
npm run build
```

> 原型无需安装：直接打开 `prototypes/galgame-v0.2.html`。

## 最新决定的优先级

1. 用户在开发过程中的最新明确决定；
2. `docs/decisions/` 已确认的实施决议；
3. V1.6.2 设计计划书及终审修订；
4. 提案文件和原型中的可选实现。

有冲突时不得默默覆盖，应在新的决议文档中说明。

## Alpha 0.1 的验收目标

- 玩家创建公司并完成第一位艺人签约；
- 完整经营第一个游戏月（排期、训练、通告、财务、事件、月结算）；
- 剧情选项会真实修改经营状态，不能只修改对白文本；
- 能存档读档，分支可重放，关键系统可测试；
- 手机竖屏可操作，PC 上用居中的竖屏舞台；
- 在第一月循环可靠之后再扩充长期选秀/羁绊/复仇内容。
